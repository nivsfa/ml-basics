# ML Basics
Basic (and possibly complex) ML concepts implementations

This repo currently contains interactive notebooks for learning about basic ML concepts and implementing them.

## Installation Guide:
### Github stuff
1. Generate an ssh key: Run `ssh-keygen -t ed25519 -C "your_email@example.com"`
1. Add key to github
1. Run `git clone git@github.com:nivsfa/ml-basics.git`

### Actual environment setup guide
1. Install uv: `curl -LsSf https://astral.sh/uv/install.sh | sh`
1. Get packages: `uv sync`
1. Load interactive app: `./load_exercise.sh` and then follow the instructions
1. Optional: Create / edit a marimo notebook: `./marimo.sh`
